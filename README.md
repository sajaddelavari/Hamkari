# هم‌ساخت — MVP نقشه زنده مشارکت

یک MVP اجرایی برای نمایش طرح به‌صورت قطعات پازل. شدت رنگ هر قطعه بر اساس تعامل و نزدیک‌شدن به تعهد واقعی افزایش می‌یابد.

## اجرا

نیازمندی: Node.js 24 یا بالاتر

```bash
npm start
```

سپس مرورگر را باز کنید:

```text
http://localhost:3000
```

## قابلیت‌های نسخه

- طرح نمونه گلخانه ۲۰ هکتاری
- نمایش قطعات همکاری در نقشه زنده و واکنش‌گرا
- ثبت مشاهده، دنبال‌کردن و اعلام آمادگی
- ثبت پیشنهاد رسمی مشارکت
- ذخیره اطلاعات در SQLite
- محاسبه مرحله و شدت رنگ در سمت سرور
- شناسه آزمایشی مستقل برای هر مرورگر
- رابط فارسی RTL مناسب موبایل و دسکتاپ

## منطق وضعیت قطعه

- مرزبندی‌شده
- دیده‌شده
- دنبال می‌شود
- اعلام آمادگی
- مذاکره جدی
- در آستانه تعهد
- تعهد قطعی

تعهد قطعی فقط پس از تأیید رسمی یک پیشنهاد رخ می‌دهد. در داده نمونه، قطعه «زمین و زیرساخت اولیه» تأیید شده است.

## ساختار

```text
server.js          سرور HTTP، API و SQLite
public/index.html  رابط اصلی
public/styles.css  طراحی واکنش‌گرا
public/app.js      رفتار کلاینت
data/               پایگاه داده؛ در اولین اجرا ساخته می‌شود
```

## نکته محصولی مهم

کلیک و مشاهده نباید به‌تنهایی «احتمال قطعی مشارکت» تلقی شود. این MVP عمداً بین توجه، اعلام آمادگی، پیشنهاد و تعهد تأییدشده تفاوت می‌گذارد تا رنگ سیستم اعتماد کاذب نسازد.
